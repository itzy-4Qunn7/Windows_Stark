# Windows_Stark
optimización de una ISO Windows ligero para la entrega final del primer semestre de sistemas operativos, La entrega estará compuesta de las siguientes partes:
1.Entrega del producto.
2.Defensa del producto.
3Examen escrito sobre la elaboración del producto.

# Condiciones obligatorias
1.Arranca desde USB y arranca en la máquina virtual.
2. Instalación 100% Unattended. la única pregunta que va a ser no unattended va a ser una pregunta realizada por el menú donde se pregunta al usuario dónde quiere descargar la ISO.
3.Edición Windows Home. La imagen debe de basarse en Windows Home.

# Requisitos de la imagen
♠ Lo más ligera posible: Se deshabilita o elimina todo lo que no es necesario.
♠ Al menos tres programas (selección definitiva).
     .Compresor: 7-Zip
     .Navegador: Brave instalado de forma silenciosa.
     .Editor de texto: Notepad++
     .Editor de código: Visual studio Code.
